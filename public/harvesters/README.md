# Custom Harvester Sprites Directory

Place your custom PNG graphics for autonomous spice harvesters here:

| Filename | Model Name | Recommended Pixel Resolution | Description |
| :--- | :--- | :--- | :--- |
| `scout.png` | Scout Harvester Mk-I | 64x64 px (or 128x128 @2x) | Fast 4-wheel rover |
| `heavy.png` | Heavy Sandcrawler Mk-II | 96x96 px (or 192x192 @2x) | 6-wheel heavy harvester |
| `titan.png` | Titan Dread-Harvester Mk-III | 128x128 px (or 256x256 @2x) | Tracked mega-harvester |

## Note on Rover Rotation
- The game rotates rover sprites along their forward direction.
- Orient your rover graphic facing **right (East / 0 degrees)** so that heading rotations match the rover's forward motion.
- Transparent background recommended.
